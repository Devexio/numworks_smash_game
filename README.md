# numworks_smash_game
Smash Numworks ist a little arcade game. The goal is to get the highest score possible by dodging the falling blocks !

# Instructions to download the programm on your Numworks

1. Copy the code of the game
2. Open the Numworks website : www.numworks.com
3. Click on your profile (top-right of your screen) then go into "My scripts"
⚠️ Make sure to have a Numworks account. If you don't have on, click on "Sign up" and follow the instructions ⚠️
4. Click on "New script" and paste the code into the dedicated zone
5. Name it with whatever name you want (I recommand "smash")
6 Click on "Save"
7. Click on "Load to calculator"

**If you struggle, here's a link to an official tutorial from the Numworks channel on Youtube**
-> https://youtu.be/bFujy7jVIIY?t=1340&si=dJAV63-UWsqUBjGd
Timecode : 22:20
